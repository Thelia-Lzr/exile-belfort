## 编辑专题文档

新增文档用清晰的英文小写文件名，正文用简体中文；在上表添加相对链接，同时更新引用该文档的入口。玩法说明维护在 README，技术与视觉细节维护在各自专题中，避免复制正文导致多处内容不一致。

修改文档时核对代码中的功能、路径和常量；命令注明工作目录，记录验证时注明日期、环境、实际结果与未验证范围。历史测试数量只代表当时状态。路径迁移保留必要跳转，链接不能指向个人机器的绝对路径。完整编辑约定见 [AGENTS.md](../AGENTS.md)。
