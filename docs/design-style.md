# 设计风格

## 游戏呈现

游戏围绕流亡者建立聚落、分配资源和推进回合展开。场景采用正交斜俯视三维模型形成 2.5D 观感；信息密度来自地图与资源，不通过增加装饰遮挡操作。

新地图是七圈独立六边形地块。地块使用低多边形、平面法线、硬边倒角、较暗侧面与可辨识的地形色。建筑采用木梁、石块、棚布等可读的部件形体；资源模型保持小尺寸下也能区分的轮廓。保持低饱和光照、Linear 色调映射与较浅阴影，避免大面积泛白。

## 战术终端 UI

界面沿用深色面板、黄色斜纹、角标、扫描线与克制的错时入场。主题集中于 `scripts/hud.gd`，装饰集中于 `scripts/tactical_chrome.gd`；新增页面优先复用现有构建函数。

| 主题常量 | 色值 | 用途 |
|---|---|---|
| `INK` | `#11171d` | 深色背景及深色文字 |
| `PANEL` | `#20272e` | 面板与卡片 |
| `LINE` | `#45515b` | 边线与分隔 |
| `GOLD` | `#e6c45b` | 主要操作、强调、斜纹 |
| `TEXT` | `#e4e9e5` | 正文 |
| `MUTED` | `#90a5ab` | 次要信息 |
| `CYAN` | `#83cfbf` | 焦点、收益与反馈 |

非法位置显示红色预览并给出文字原因；库存不足、选中、悬停和禁用状态须可区分。资源使用图标加数值，净变化紧邻库存；按钮标签和提示使用明确中文。中文字体依赖系统回退，验证时检查实际显示而非只看节点属性。

四个势力通过旗帜、徽记、配色和可编辑背景区分，不附带隐藏经济加成。新的风格参考不能变成直接复制其他游戏的品牌素材。

## 交互与动效

- 地块选择短暂下压并归位；连续点击和重复冲击不得导致高度漂移。
- 建造动画表现部件拼装，完工后保留轻微循环动作；规则在建造确认时已经生效，不等待动画。
- 工坊采用空中组装、整栋下砸和单圈向外衰减的冲击波，不能因表现变化改变建造范围或收益。
- UI 的扫光、亮闪与扫描条服从同一动态开关；关闭动态效果应立即恢复完整静态建筑及地块高度。
- 装饰不占布局、不拦截输入，不能覆盖费用、提示和可点击区域。维持镜头拖动与右键取消的区分。
- 音效短促并通过统一管理器控制音量、静音和密集播放；新增音效应实际试听。

## 视觉验收

涉及视觉的 PR 提供实际渲染截图，至少检查受影响页面、中文可读性、地图边缘与点击反馈；动画变更同时检查运行中关闭动态效果。参考截图位于 `../previews/` 与 `../artifacts/hex7-ui/`，重生成命令见 [贡献说明](../CONTRIBUTING.md)。
